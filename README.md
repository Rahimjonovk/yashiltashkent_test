# Yashil Toshkent

Карта проблем с деревьями и зелёными зонами Ташкента: сайт, панель модератора, **страница супер-админа** и **Telegram-бот**.
Сайт и бот работают с **одними и теми же данными** на одном сервере: обращение, отправленное с компьютера, сразу видно в боте, и наоборот.

Зависимостей нет (только Node.js 18.17+). Leaflet лежит в `public/vendor`.

## Запуск

```bash
npm start            # затем откройте http://localhost:3000
```

При **первом запуске** в консоли печатается логин и пароль супер-админа (случайный пароль). Войдите на `/login.html` и сразу смените пароль
(вкладка «Mening hisobim»). Свой пароль можно задать заранее в `.env` (`SUPERADMIN_PASSWORD`).

> Страницы теперь отдаёт сам Node-сервер. Если по привычке откроете их через Live Server (порты 5500–5503) или с диска, `auth.js` сам
> обратится к API на `http://localhost:3000`, но сервер всё равно должен быть запущен.

Все настройки (необязательные) — в `.env` (см. `.env.example`):

| Переменная | Для чего |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от @BotFather. Без него бот выключен, сайт работает |
| `PUBLIC_URL` | https-адрес сайта: нужен для кнопки «Saytda» в сообщениях бота |
| `SUPERADMIN_LOGIN` / `SUPERADMIN_PASSWORD` | первый супер-админ (только при первом запуске) |
| `GEO_CONTACT` | e-mail/URL для заголовка User-Agent запросов адреса (требование политики OpenStreetMap) |
| `TRUST_PROXY=1` | если сервер стоит за nginx/Caddy/Cloudflare |
| `PORT`, `DATA_DIR` | порт и папка данных (`data/`) |

## Не подходит пароль супер-админа

Супер-админ создаётся **только при первом запуске** (когда в `data/db.json` его ещё нет), поэтому изменение `SUPERADMIN_PASSWORD` в `.env` позже ничего не меняет.
Если пароль потерян или не подходит, остановите сервер (Ctrl+C) и выполните:

```bash
npm run reset-admin                     # новый случайный пароль для логина superadmin
npm run reset-admin -- LOGIN            # то же для другого логина (будет создан, если его нет)
npm run reset-admin -- LOGIN NEWPASS1   # задать пароль самому (минимум 8 символов, буква и цифра)
```

Команда печатает логин и новый пароль; затем снова запустите `npm start`. После 5 неверных попыток вход блокируется на 30 секунд.

## Telegram-бот

1. В Telegram откройте **@BotFather** → `/newbot` → получите токен.
2. Впишите его в `.env`: `TELEGRAM_BOT_TOKEN=123456:ABC...` и перезапустите `npm start`. В консоли появится `Telegram bot: @имя ишга тушди`.
3. Бот работает через long polling: **домен, https и вебхуки не нужны**, но серверу нужен выход в интернет к `api.telegram.org`.

Что умеет бот (интерфейс на узбекском, как и сайт):

* `/yangi` — подать обращение: **телефон** (кнопка «📱 Telefon raqamni yuborish», спрашивается один раз) → геопозиция (кнопка, скрепка → «Joylashuv») **или текст адреса** → бот сам определяет полный адрес и **район** (никакого выбора района) → тип → порода/количество → опасность → описание → фото → подтверждение.
  * Телефон берётся только через кнопку Telegram «поделиться контактом»; контакт чужого человека или номер, напечатанный вручную, бот не принимает. Номер видят только модераторы и супер-админ (карточка в боте, панель модератора, вкладка «Telegram bot»); обычным посетителям, в публичный API и в группу уведомлений он не попадает.
  * Район определяется автоматически: сначала по данным OpenStreetMap, а если OSM район не назвал — по ближайшему центру района (приблизительно, около границ районов возможна неточность).
* `/royxat`, `/mening`, номер `TD-XXXXXX` — списки и поиск; `/obuna` — получать уведомления о новых обращениях; `/id` — узнать ID чата.
* **Привязка аккаунта сайта**: на сайте кнопка «Telegram» (или страница «Mening hisobim») → «Botda ulash», либо `/link КОД`.
  Привязанный пользователь видит в боте и свои обращения с сайта; ответ модератора приходит ему в Telegram.
* **Модератор** (аккаунт с ролью moderator/super admin, привязанный к боту): получает карточку каждого нового обращения (с фото и кнопками),
  меняет статус кнопками «Koʻrib chiqilmoqda / Hal qilindi / Rad etish» и пишет ответ прямо в боте. `/stat` — статистика.
* **Группа/канал уведомлений**: добавьте бота в группу, напишите там `/id`, вставьте ID в супер-админке (вкладка «Telegram bot»).
  Кнопки в группе работают только для привязанных модераторов.

**Панель модератора** (`admin.html`) — только список заявок с фильтрами. Карты на странице нет: мини-карта (190 px) появляется внутри карточки заявки, когда модератор нажал на заявку, и исчезает при закрытии. Если модератор откроет главную страницу `index.html`, его автоматически вернёт в панель; полная карта остаётся у обычных посетителей и у супер-админа.

Как синхронизируется: сайт и бот вызывают один и тот же слой `server/service.js`. Любое изменение (новое обращение, ответ, удаление)
мгновенно уходит на открытые страницы по SSE (индикатор «Jonli») и в Telegram.

## Полный адрес по клику на карте

Клик в любом месте карты показывает всплывающее окно с адресом вида **«Chilonzor tumani, Bunyodkor koʻchasi, 43-uy»** и кнопкой
«Shu joyga murojaat yuborish». В форме адрес подставляется автоматически вместе с районом (поле «Tuman»), сохраняется в обращении
и отображается в списке, карточке, панели модератора, CSV и в боте.

Адрес определяется на сервере через OpenStreetMap Nominatim (кэш, не чаще 1 запроса в секунду). Если в OSM у улицы нет номера дома, сервер
ищет ближайший дом через Overpass и пишет «…, 7A-uy yaqinida». Если адрес не найден, район и мольджал можно ввести вручную.

## Страница супер-админа (`/superadmin.html`)

* **Umumiy** — счётчики, статусы, динамика за 14 дней, районы, типы, каналы (сайт/Telegram), среднее время ответа.
* **Foydalanuvchilar** — создать пользователя, роль (пользователь / модератор / супер-админ), блокировка, сброс пароля, отвязка Telegram, удаление.
  Последнего активного супер-админа нельзя понизить, заблокировать или удалить.
* **Telegram bot** — состояние бота, чат уведомлений, тестовое сообщение, список пользователей бота (блокировка, подписка).
* **Jurnal** — журнал действий (кто, когда, что; в т.ч. действия через бот).
* **Maʼlumotlar** — резервная копия (JSON) и перенос данных из старой версии (`localStorage`).
* Модераторы работают в `/admin.html` (таблица, фильтры, ответ, CSV); управление людьми доступно только супер-админу.

## Безопасность

Пароли — scrypt; сессии — случайные токены, на сервере хранятся только их хэши; блокировка перебора пароля; лимиты на отправку обращений и
запросы адреса; проверка всех полей и фото на сервере; все пользовательские тексты экранируются; токен бота живёт только в `.env`.
Перед публикацией в интернет включите https (nginx/Caddy) и `TRUST_PROXY=1`.

## Данные

Папка `data/`: `db.json` (обращения, ответы, пользователи, журнал) и `photos/`. Копируйте её целиком. Файл пишется атомарно, раз в 10 минут делается `db.json.bak`.

## Тесты

`npm test` — сквозные тесты с подставными Telegram и Nominatim (16 сценариев: адрес, права, привязка, сайт→бот, бот→сайт, ответы с обеих сторон, группа, валидация).
